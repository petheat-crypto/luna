Луна Академия · Мои дела

Помощь

Короткая инструкция по планировщику.

Вход

Для демонстрации можно войти как nina с паролем 1234 или как test с паролем test. Также доступна кнопка «Войти через Google».

Добавить дело

Нажмите «Добавить дело», выберите готовый шаблон или впишите название. Затем задайте день, время и повторение и нажмите «Сохранить дело».

Отметить выполненным

Нажмите «Сделано» у дела. Оно появится в разделе «Сделано». Если отметили случайно, нажмите «Вернуть в дела».

Важно: дела сохраняются в localStorage этого браузера. Они не синхронизируются между устройствами; очистка данных сайта в браузере может удалить сохранённый список.
